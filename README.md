# E-Commerce Data Warehouse

## Project Overview

This project focuses on building an E-Commerce Data Warehouse using the Olist Brazilian E-Commerce dataset.

The project demonstrates data loading, staging, data warehouse development, dimensional modeling, data transformation, validation, and business reporting.

## Objective

The main objective is to transform raw e-commerce data into a structured data warehouse and data mart that can be used for business analysis and reporting.

## Dataset

Olist Brazilian E-Commerce Public Dataset.

## Technology Stack

- MySQL
- SQL
- Data Warehouse
- Data Mart
- Dimensional Modeling

## Architecture

Source Data → Staging Layer → Data Warehouse → Data Mart

## Data Warehouse

The warehouse contains:

- Dimension Tables
- Fact Tables
- Date Dimension
- Customer Dimension
- Product Dimension
- Seller Dimension
- Category Dimension

## Data Mart

The project includes data marts for analyzing:

- Sales
- Products
- Categories

## Key Business Metrics

- Total Orders
- Total Revenue
- Total Freight
- Average Item Price
- Products Sold
- Sales by Date
- Sales by Customer State

## Project Outcome

The project converts raw e-commerce data into structured analytical data that can support business reporting and decision-making.
